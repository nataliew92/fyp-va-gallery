# fyp-va-gallery
A generous interface prototype for browsing the Victoria and Albert (V&A) collection using an interactive map-based interface to explore artefacts by country of origin. 

## About this project
This is part of a final year university project (CIS3425 - Edge Hill University). It is a generous interface prototype that was designed to encourage university students who may not know what to search for to explore and discover museum collections through browsing. It uses the V&A Collections API to populate artefact content.

## Features
- Interactive world map
- Country-based artefact browsing
- Dynamic categories per country
- Inspiration menu for serendipitous discovery
- Onboarding screen

## Technologies used
- HTML5, CSS3, JavaScript (ES2020)
- Leaflet.js (v1.9.4) for interactive mapping
- Flag Icons CSS library
- Google Fonts (Lora and Lato typefaces)
- V&A Collections API v2 for artefact data
- CartoDB Voyager (map tile provider)
- Natural Earth GeoJSON (country boundary data)

## Running locally
1. Clone the repository
2. Open the project folder
3. Open index.html directly in a modern browser, or run it via VS Code's Live Server extension for best results
4. No installation or build steps required
Note: an internet connection is required to load the V&A API and CDN-hosted libraries.

## Known limitations
- Designed for desktop screens; may not function as intended below 900px
- Country filtering uses the V&A's loose place-name matching, so some bleed-through between countries is possible
- Requires an internet connection to load the API and external libraries
